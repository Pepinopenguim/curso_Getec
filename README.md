# Curso Getec - Python

Bem-vindo ao repositório do **Curso Getec de Python**!

Este repositório reúne todos os arquivos, exercícios e materiais utilizados durante o curso de Python oferecido pelo Getec. Aqui você encontrará desde exemplos básicos até conteúdos mais avançados, com o objetivo de facilitar seu aprendizado.

## Conteúdo do repositório

- Notebooks Jupyter (`.ipynb`): Exemplos práticos e exercícios para acompanhar as aulas.
- Scripts Python (`.py`): Códigos ilustrativos de conceitos fundamentais.
- Materiais de apoio: Textos, links úteis e recursos extras para aprofundar seus estudos.

### O que você vai aprender

    - Sintaxe e comandos básicos do Python
    - Tipos de dados (int, float, string, list, dict, etc.)
    - Estruturas de controle (if, for, while)
    - Funções e módulos
    - Manipulação de arquivos
    - Uso de bibliotecas populares
    - Práticas de programação e resolução de problemas
